BHOOMISETU V3.6 - MULTI-PROJECT WORKSPACE

What changed:
1. Projects page now supports multiple project records.
2. Create Project creates a NEW independent project instead of overwriting the current one.
3. Each project stores its own workflow, parcels, owners, documents, grievances, valuation, compensation, payment and completion state.
4. Projects page shows all projects and lets you Switch & Open any project.
5. Dashboard Projects count now shows the total projects in the workspace.
6. Dashboard Parcel Map & Delay Monitor preview was removed to reduce visual crowding. The complete Parcel Map remains under Land Parcels.
7. Parcel IDs are generated per project so demo parcel records do not collide between projects.
8. Existing local-only safety model is preserved: no API keys, no live government database, no real payments and no external backend.

HOW TO RUN
1. Extract the ZIP.
2. Open the BHOOMISETU folder.
3. Double-click index.html.
4. Open Projects.
5. Click + Create Project.
6. Enter a new project name, district and area.
7. Click Create Project & Open.
8. Return to Projects to see both project records.
9. Use Switch & Open to move between projects. Their data remains separate.

IMPORTANT
This is an SIH demonstration prototype using sample data. It is not a production government system.
