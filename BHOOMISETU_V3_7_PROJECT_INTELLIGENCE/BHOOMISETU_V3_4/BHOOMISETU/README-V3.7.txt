BHOOMISETU V3.7 — PROJECT-WISE MONITORING

What is new:
- Multiple acquisition projects can be created and stored separately in browser storage.
- Projects page now supports project search by ID, name, district, purpose or location.
- Every project shows status, current stage, workflow progress, delay probability and estimated remaining time.
- Opening/switching a project makes its own workflow, parcels, owners, documents, grievances and compensation the active dashboard data.
- Dashboard clearly identifies the active project and includes a Switch Project action.
- Project-specific intelligence is calculated from that project's demo workflow state.
- No external APIs, API keys, GIS service, payment gateway or real government database are used.

Safe demo notes:
- This is a local SIH demonstration using sample data only.
- Decision-support percentages and time estimates are illustrative prototype rules, not official predictions.
- Data is stored locally in the browser using localStorage.

Run:
1. Extract the ZIP.
2. Open BHOOMISETU/index.html in Chrome or Edge.
3. Go to Projects.
4. Use + Create Project to add another demo project.
5. Search and switch projects; verify that each project has separate workflow data.
6. Use Profile > Reset Demo if you want to return to the original sample project.
