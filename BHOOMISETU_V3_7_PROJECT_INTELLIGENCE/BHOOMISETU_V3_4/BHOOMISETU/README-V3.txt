BHOOMISETU V3 — END-TO-END WORKFLOW
CODESTROM • SIH 2026 • SIH26016

HOW TO RUN
1. Extract this ZIP.
2. Open the BHOOMISETU folder.
3. Double-click index.html.
4. Use the left sidebar or Dashboard's “Continue Current Stage”.
5. Follow the stages in order. Each stage unlocks only after its prerequisite is completed.

DEMO JOURNEY
Project Identification → Location Identification → Preliminary Survey → Measurement & Mapping → Parcel Identification → Landowner/Stakeholder Identification → Document Verification → Social/Environmental Assessment → Acquisition Notification → Objections/Grievances → Valuation → Compensation Calculation → Compensation Approval → Award → Payment/Disbursement → Possession → Final Handover → Project Completion.

SAFETY
- Local HTML/CSS/JavaScript only.
- No API keys, npm packages, backend server, payment gateway, or real government database.
- Uses sample/demo data and browser localStorage for the current demo.
- Prototype is for SIH demonstration and is not a production government system or legal workflow.

RESET
Click the District Admin profile at top-right → Reset Demo.

TIP FOR SIH DEMO
Start at Dashboard → Continue Current Stage and narrate the connected lifecycle. You can also use Acquisition Workflow to show all 18 stages.
